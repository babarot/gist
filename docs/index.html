gist

Read and edit your GitHub Gists from the terminal.

GitHub Releases

What it does

  • Your gists in a list, with the files of the one under the cursor beside it.
  • A filter, fuzzy over what you type, with file:, lang:, vis: and desc: to look in one thing.
  • Edits in your own editor, with the diff to read before anything is pushed.
  • A push that stops when the gist changed on GitHub since you opened it.
  • A CLI that does the same from a script.

Install

brew install babarot/tap/gist
nix profile install github:babarot/nur-packages#gist
go install github.com/babarot/gist/v2@latest

Or take a binary from the releases. gist reads GitHub with the account gh is logged in to, or with GH_TOKEN or GITHUB_TOKEN.

Use it

gist                               # the list
gist new --public main.go go.mod   # a gist, printing its URL
gist view 1a2b3c main.go           # a file as it is written
gist edit 1a2b3c main.go           # in your editor

Press ? in the list for every key. The README has the rest.
